Deployment & Installation

  • 1

    Download the APK

    Open the repository's **GitHub Releases** page on your Android device and download the latest version of `family_pic_in_game.apk`.

  • 2

    Enable Installer Permissions

    If prompted by your browser or files app, allow installation from **Unknown Sources**. You can find this setting in your Android device's settings under **Apps > Special app access > Install unknown apps**.

  • 3

    Install the Application

    Open the downloaded APK file and click **Install**. Once completed, tap **Open** to boot up the Neon Arcade dashboard.

  • 1

    Download the IPA Package

    Navigate to **GitHub Releases** on your device and download the application package file named `family_pic_in_game.ipa`.

  • 2

    Install AltStore & AltServer

    Download AltServer on your Mac/PC from the official website [altstore.io](https://altstore.io/). Connect your iPhone to your computer via USB and use AltServer to install AltStore on your device.

  • 3

    Enable Developer Mode

    On iOS 16+, you must enable Developer Mode. Navigate on your device to **Settings > Privacy & Security > Developer Mode**, toggle it **On**, and follow the prompts to reboot your device.

  • 4

    Sideload the IPA

    Open AltStore on your iPhone, navigate to the **My Apps** tab, tap the **+** button in the top-left, and select the downloaded `family_pic_in_game.ipa` file to install it.

Is Sideloading with AltStore Safe?

AltStore is currently the most popular, secure, and transparent open-source sideloading solution for non-jailbroken iOS devices. Because it works outside Apple's standard distribution, here is an objective breakdown of how its security mechanisms protect your device:

No Jailbreak Required

Unlike old-school sideloading methods, AltStore does not modify or exploit your device's core operating system files. It operates entirely within Apple's official sandbox, using sandboxed API calls to run your app.

Official Apple APIs

AltStore signs applications using your own Apple ID credentials. It essentially acts as a local proxy running Xcode (Apple's development environment) to install your own app for testing purposes.

Fully Open Source

The code for both AltStore and AltServer is fully open-source and reviewable on GitHub. Your logins are sent directly to Apple's authentication servers and are not stored or transmitted to third parties.

Security Best Practice: Because AltStore requires you to input an Apple ID to request development profiles, we highly recommend **creating a separate, secondary Apple ID** purely for signing apps via AltStore. This ensures your primary personal iCloud account remains completely separate.
