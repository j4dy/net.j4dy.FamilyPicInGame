Neon Cyber Arcade Suite

Five classic, fully integrated games featuring customizable participant roles and neon-themed canvas interfaces.

Family Slingshot

Aim and launch family bird avatars using elastic cords to crash fortresses. Powered by Contact Normal velocity calculations, bird characters plow cleanly through wood and glass blocks with minimal speed decay.

Family Pac-Man

Escape opponent family ghosts in a connected retro grid. Features Blinky, Pinky, Inky, and Clyde authentic pathfinding AI, frightening power pellets, wrap tunnels, and snapshot-safe copy collections to prevent CME crashes.

Family Nibbles

Collect food to grow your snake body. Watch your segments alternate dynamically with other family faces! Integrates border portal ripple exit/entrance graphics and dual controller support (Swipes + precise D-Pad).

Flappy Flight

Steer your custom astronaut capsule between neon obstacles. Includes 3 customizable gap difficulty levels: Space Cadet (Easy - 340 px), Pilot (Medium - 280 px), and Astronaut (Hard - 220 px) displayed on-screen.

Core Engines & Systems

Designed using Flutter and Dart to run locally, efficiently, and with total privacy.

Circular Crop Engine

Integrates multi-touch gesture listeners to position character images safely behind an interactive cyan circular boundary mask.

  • Modern permissionless image picker
  • Zero invasive storage read/write permissions
  • Native matrix-equivalent scaling and offset translation
  • Output downsampling to avoid memory crashes

Self-Sufficient Database

Stored profiles are structured in JSON arrays on SharedPreferences and written as PNGs inside the application's secure private folder.

  • Automatic cartoon face drawing on first boot
  • Vibrant default character vectors loaded dynamically
  • Instant file deletions and database CRUD operations
  • Total data wipe upon uninstalling the application

High-Readability Upgrade

To ensure comfortable play across all device sizes, we have optimized the interface layout. Buttons on the setup screens and in-game overlays are styled with a prominent 22 logical pixels font size with expanded tap margins.

Additionally, obscure icon-only actions have been replaced by text buttons displaying RESET in 18 logical pixels bold text, making controls immediately clear and readable.
